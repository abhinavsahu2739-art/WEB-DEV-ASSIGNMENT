# HTML Assignments — Professional HTML + CSS

## Files
1. `01-basic-page.html` — Basic page, title and headings
2. `02-resume.html` — Text-only resume content
3. `03-portfolio.html` — Portfolio with navigation and images
4. `04-semantic-portfolio.html` — Semantic HTML improvement
5. `05-about-me.html` — About Me project
6. `06-college-information.html` — College information page
7. `07-product-specification.html` — E-commerce product specification table
8. `08-student-registration.html` — Student registration form
9. `09-job-application.html` — Professional job application form
10. `style.css` — Shared responsive styling

## How to use
- Keep all HTML files and `style.css` in the same folder.
- Open any `.html` file in a browser to preview it.
- Replace placeholders such as `Your Name`, sample email/phone, college details, and sample product data before submitting.
- Images are loaded from Unsplash and therefore need an internet connection.
- Forms are frontend demonstrations only. They do not save or send submissions without a backend.

## Learning note
The assignment list is based on `HTML_Assignments.pdf`. Professional CSS styling has been added to improve presentation while keeping the HTML visible and understandable for practice.
